
# 📲 Push Notifications App

A Flutter app that demonstrates how to receive **push notifications** through **Firebase Cloud Messaging (FCM)** and display them as **local notifications** with `flutter_local_notifications`, in all three app states: foreground, background and terminated (killed).

---

## ✨ Features

- Receive push notifications from **Firebase Cloud Messaging**.
- Handle messages when the app is in the **foreground**, **background**, or **killed**.
- Display notifications locally using `flutter_local_notifications` with high importance and priority.
- **Big picture** notifications on Android: the image is downloaded from a URL sent in the payload (via `dio`).
- Automatic subscription to the `all_users` **topic** for broadcast messages.
- FCM token retrieval (logged to the console), with a ready-made hook to send it to your server.
- Test pushes easily through **Postman** using the FCM HTTP v1 API.

## 🧠 How It Works

1. `main.dart` initializes Firebase, then runs `PushNotificationsService.init()` and `LocalNotificationService.init()`.
2. `PushNotificationsService.init()`:
   - requests notification permission,
   - gets the FCM token,
   - registers the background handler (`FirebaseMessaging.onBackgroundMessage`),
   - listens to foreground messages (`FirebaseMessaging.onMessage`),
   - subscribes the device to the `all_users` topic.
3. Every incoming message (foreground or background) is passed to `LocalNotificationService.showBasicNotification`, which reads `title`, `body` and `image_url` from the message's **`data`** payload and shows the notification.

> **Important:** the app reads the content from `message.data`, not from the `notification` block. Send your messages as **data messages** (see below).

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mo7amedsoliman7/Push-Notifications-App.git
cd Push-Notifications-App
```

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Connect your own Firebase project

1. Create a project in the [Firebase Console](https://console.firebase.google.com/).
2. Install the FlutterFire CLI and configure the app:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   This regenerates `lib/firebase_options.dart` and the platform config files for your project.
3. Make sure Cloud Messaging is enabled for your Firebase project.

### 4. Run the app

```bash
flutter run
```

On start, the app asks for notification permission and prints the **FCM token** in the debug console.

## 🧪 Testing Push Notifications

You can send a test message with **Postman** using the FCM HTTP v1 API:

- **Endpoint:** `POST https://fcm.googleapis.com/v1/projects/<YOUR_PROJECT_ID>/messages:send`
- **Headers:** `Authorization: Bearer <OAuth2_ACCESS_TOKEN>`, `Content-Type: application/json`
- **Body (to a single device):**

```json
{
  "message": {
    "token": "<DEVICE_FCM_TOKEN>",
    "data": {
      "title": "Hello 👋",
      "body": "This is a test push notification",
      "image_url": "https://example.com/image.jpg"
    }
  }
}
```

- **Body (to all subscribed users):** replace `"token": "<DEVICE_FCM_TOKEN>"` with `"topic": "all_users"`.

Step-by-step guide on getting the access token and using Postman: [Send push messages via Postman and FCM API v1](https://medium.com/@sekitafilovic/send-push-messages-via-postman-and-firebase-cloud-messaging-api-v1-3c63bc69fec8).

## 🔧 Customization

- **Send the token to your backend:** implement `PushNotificationsService.sendTokenToServer`.
- **Unsubscribe on logout:** call `messaging.unsubscribeFromTopic('all_users')`.
- **Change topic:** edit the `subscribeToTopic('all_users')` call.
- **Handle notification taps:** listen to `LocalNotificationService.streamController.stream`.
- **Notification channel:** adjust `channel_id` / `channel_name` in `LocalNotificationService`.
